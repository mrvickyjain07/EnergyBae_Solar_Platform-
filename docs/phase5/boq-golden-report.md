## 7. Assumptions and inferences used to compare [INF]

- **Input mapping** (`legacyInputsFromFixture`):
  - capacity ← "Required Solar Capacity" B (B1, *not* C1);
  - phase ← B4 (3 → 3-Phase, otherwise 1-Phase);
  - floors, inverter floor, inverters, rows, heights, strings, batteries ← their labelled B cells (non-numeric → 0);
  - inverter cost ← first inverter line rate;
  - panel type ← module spec text ("Non-DCR" → NDCR).
- **Earthing type = ESE**, because every workbook LA row specifies "ESE Type". The workbooks have no earthing-type input.
- **Line mapping** (`classifyLine`): workbook rows are matched to legacy lines by Material / Specification text; several rows of one kind are summed (e.g. Ananda 40.2's three inverter rows).
- **Reasons and classes** come from `REASONS` in `workbookGolden.ts`. They explain observed differences and do not decide which side is correct.
- **Workbook values** are the cached results saved in the files (Google Sheets exports). Cross-checked cell by cell against an independent openpyxl extraction: 1,232 cells, 0 differences apart from one blank cell read as "" vs null.
